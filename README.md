# Projet_caerus
Ce dépôt regroupe l’ensemble des travaux réalisés dans le cadre du Projet CAERUS – Semestre 5 (Électronique analogique). L’objectif est de simuler, concevoir et réaliser un système de détection de proximité par ultrasons (HC‑SR04), ainsi qu’un système de signalisation basé sur un bargraph à LEDs.
